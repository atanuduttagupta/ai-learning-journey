# 📘 Day 16 – Regression Concepts & Linear Regression

## 🚀 Overview
This project is part of my AI Learning Journey, where I am building machine learning concepts from the ground up with hands-on implementation.

In this module, I explored Regression Models, which are used to predict continuous values such as price, salary, or risk score.

---

## 📊 What I Covered

### 🔹 1. Simple Linear Regression
- Predict Salary based on Experience
- Formula: Salary = m × Experience + b
- Learned slope and intercept meaning

### 🔹 2. Multiple Linear Regression
- Predict House Price using:
  - Area
  - Location
  - Rooms
- Used StandardScaler
- Avoided data leakage

### 🔹 3. Polynomial Regression
- Modeled non-linear relationships
- Used PolynomialFeatures
- Observed overfitting behavior

### 🔹 4. Ridge & Lasso Regression
- Ridge → Shrinks weights
- Lasso → Makes some weights zero (feature selection)

---

## 🧠 Key Concepts
- Train-Test Split
- Scaling (StandardScaler)
