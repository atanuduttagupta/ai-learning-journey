## 🧠 What is Supervised Learning?

Supervised Learning is a type of Machine Learning where a model learns from labeled data.

- Input (X) → Output (y) is known  
- Goal → Learn a function: y = f(X)

The model learns patterns from past data to make future predictions.

---

## 📊 Types Covered

### 🔹 Regression
- Predicts continuous values  
- Example: Salary prediction  

### 🔹 Classification
- Predicts categories  
- Example: Loan approval (Yes/No)

---

## ⚙️ ML Training Workflow

1. Make predictions  
2. Calculate error (loss)  
3. Update model  
4. Repeat  

This loop is powered by optimization (Gradient Descent).
