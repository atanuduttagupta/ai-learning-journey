## 🚀 Overview
This project focuses on evaluation metrics for classification models, which are critical for real-world machine learning systems.

Understanding how to evaluate models is what makes you industry-ready.

---

## 📚 Topics Covered

### 🔷 Confusion Matrix
- TP, TN, FP, FN
- Understanding model errors
- Business impact of errors

### 🔷 Accuracy (⚠️ Limitations)
- Works poorly on imbalanced data
- Example: Fraud detection

### 🔷 Precision & Recall
- Precision → Trust in predictions
- Recall → Ability to capture positives
- Trade-off between both

### 🔷 F1 Score
- Harmonic mean of Precision & Recall
- Useful for imbalanced datasets

### 🔷 ROC Curve
- TPR vs FPR
- Performance across thresholds

### 🔷 AUC
- Measures overall model quality
- 1.0 = Perfect, 0.5 = Random

### 🔷 Threshold Tuning
- Lower threshold → Higher Recall
- Higher threshold → Higher Precision
- Critical for production ML systems
