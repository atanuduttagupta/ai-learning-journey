# 📊 Day 29: Poisson Distribution (Traffic Simulation)

## 🚀 Overview
This project simulates real-world website traffic using the **Poisson Distribution**.

Even if the average clicks per minute is constant (~5), actual traffic varies:
- Some minutes → fewer clicks  
- Some minutes → spikes  

---

## 🎯 Key Concept
Poisson Distribution models:
> Number of events in a fixed time interval

---

## 🧠 Insight
Real systems don’t follow fixed numbers — they follow distributions.

---

## ⚠️ Takeaway
> Don’t design for the average  
> Design for the spikes  

---

## 🔗 Applications
- Web traffic  
- API requests  
- System load
