# Day 07 - Bayes Theorem (Medical Diagnosis)

## 🚀 Problem
If a test is 99% accurate, does a positive result mean you have the disease?

## 🧠 Insight
No. When the disease is rare, false positives can dominate.

## 📊 Key Concept
Bayes Theorem helps update probability based on evidence.

## 🛠 What this project includes
- Probability setup
- Bayes calculation
- Real-world intuition using 1000 people

## 💡 Takeaway
Accuracy alone is misleading. Base rate matters.
