# 📊 Fraud Detection using Statistical Techniques

## 🚀 Overview
This project demonstrates how to detect anomalies in transaction data using:
- Variance
- Covariance
- IQR (Interquartile Range)
- Z-score

## 🧠 Problem
Detect fraudulent transactions from normal transaction behavior.

## 🛠️ Techniques Used
- IQR → Robust outlier detection
- Z-score → Statistical anomaly detection
- Covariance → Feature relationship understanding

## 📊 Results
- IQR performs better for skewed real-world data
- Z-score works well for normally distributed data

## 📁 Files
- fraud_detection_day09.ipynb → Main notebook
- solution.py → Python script version

## 🔥 Key Insight
Understanding your data is more important than jumping to ML models.
